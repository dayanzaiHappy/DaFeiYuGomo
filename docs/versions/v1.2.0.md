# v1.2.0

2026-11-10。台词换成「DeepSeek 小鲸鱼」人设，互动事件铺开。

> 本文件在文档重构时据 `v1.2.0` 快照（提交 `b851c96`）与当时的设计记录整理，描述的是 1.2.0 的行为。

## 为什么改

1.1 的台词是功能性提示（「我建议在第 8 行第 8 列……」），读起来像说明书，没有角色感。同时气泡文案是在 `refreshAll()` 里随手取随机数的，切一次皮肤、开一下音效开关，台词就换一句——用户看到的是「界面自己在说话」。

这一版只动两件事：文案本身，和文案的生成方式。规则、搜索、参数一概没改。

## 人设约束

台词按一份社区人设卡落地，硬约束如下（这些是写文案时的判据，不是风格建议）：

| 维度 | 约束 | 落到代码里 |
|---|---|---|
| 身份 | DeepSeek 娘 / 小鲸鱼，不是客服、不是百科 | 台词里不出现「提示功能」「模式」 |
| 性格 | 傲娇嘴硬，心软不表现 | 输了不服但认，赢了不得意忘形 |
| 长度 | 一句话 1~10 字 | 状态台词控制在 4~12 字 |
| 标点 | 少用句号，一条消息只发一行 | 状态台词不用句号、不换行 |
| 语气词 | 不每句都加「～」「哦」「呢」「啦」「呀」 | 一个都不留 |
| 自称 | 只用「我」或省略主语 | 不用「本小姐」这类二创腔 |
| 禁忌 | 不总结、不升华、不说教 | 删掉所有「再来一局？」式的收尾 |
| 彩蛋 | 「大肥鱼」是雷点 | 开局低概率抗议这个外号；连胜三局后自嘲摆烂 |

## 文案机制

- 21 个槽位词池（开局、等你、思考中、自己回合、双人局、胜利、失败、和棋、悔棋、重开、点错、非自己回合、连胜、摆烂、外号……），共 79 条。
- `pickLine`：洗牌袋，一个词池发完一轮才重洗，同一轮内不重复。
- `pickLineStable(ns, pool, sig)`：以「槽位 + 手数」为签名做确定性选择。重绘不换词，只有局面真的变了才换。这是「切皮肤不换台词」的唯一手段。
- `resetLines`：新开一局时清空袋位状态，否则上一局的进度会带进来。

## 互动事件

| 事件 | 反应 |
|---|---|
| 开局 | 打招呼，偶尔抗议「大肥鱼」这个外号 |
| 悔棋 / 重开 | 吐槽，悔棋到第 3 次换成「用户你够了」 |
| 点错格子、非自己回合 | Toast 提示，不进气泡 |
| 连胜三局 | 摆烂台词，本局只触发一次 |
| 提示计算超过 5 秒 | 气泡显示「已思考 N 秒」，每秒刷新 |
| 结算 | 弹窗只报结果，台词交给气泡，两处不重复 |

## 提示解释

- `reasonFor` 改为返回**词池**，由调用方抽一条；按棋型（能成五 / 必须挡五 / 造活四 / 堵活三 / 普通）分池。
- `confidenceFor` 增加必杀短路：一手成五或必须挡五时直接给「确定」语气，不看搜索 Q 值。否则会出现「这一步直接连成五子了。局面有点紧，先稳住。」
- `buildHintView` 用 `WeakMap` 按 `SearchResult` 记忆化：同一次搜索结果，重绘多次也只生成一遍文案。
- `#hint-text` 加 `min-height: 3.4em`：台词只有 4~12 字，锁两行高度，状态切换时右侧栏不会上下跳。
