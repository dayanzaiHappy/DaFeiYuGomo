# v1.1.0

2026-11-10。三档扩四档，参数整体重标定，根节点噪声从「全部候选」收进「支持集」。

> 本文件在文档重构时据 `v1.1.0` 快照（提交 `560fdb7`）与当时的设计记录整理，描述的是 1.1.0 的行为。

## 1.0.0 的已知问题

这一版同时在处理三件事：

1. **档位区分度不够**。4 / 16 / 64 的 `sims` 跨度太大，简单档只有 4 次模拟，等于「只看先验前 4 名」——排在第 8 的防守点永远看不到，这是「活三不堵」的直接原因；困难档 64 次又不足以覆盖全宽候选。
2. **噪声撒得太散**。α = 0.1 的 Dirichlet 加在全部根子节点上，中局有上百个候选，无意义的点也会分到 10%~16% 的质量，把真正的防守点挤出前列。
3. **温度在低预算下几乎无效**。采样权重是 `visits^(1/τ)`，低 `sims` 时被访问过的子节点全是 1 次访问，权重恒等，τ = 1 与 τ = 0.1 给出相同分布。τ 只在 visits 出现差异后才生效。

## 四档难度

`sims` 改为首项 40、公比 √e 的等比数列，逐项取整：

```ts
40, 66, 109, 179        // 40 · (√e)^n, n = 0..3
```

| 档位 | sims | τ | ε | topM |
|---|---|---|---|---|
| 简单 | 40 | 1.0 | 0.10 | 12 |
| 普通 | 66 | 0.6 | 0.06 | 10 |
| 困难 | 109 | 0.3 | 0.03 | 8 |
| 地狱 | 179 | 0.1 | 0.01 | 8 |

- 新增「地狱」档，`τ` 与 `ε` 都比困难再降一档。
- 提示预算从 256 上调到 292，是手算的等比数列第五项；与 `40·(√e)⁴` 的取整值不符。
- 采样池 `K` 统一为 3。

## 噪声支持集

根节点噪声不再作用于全部候选，先过三道闸再撒：

1. 质量护栏：`prior ≥ 0.5 × max(prior)`；
2. 位置护栏：到上一手的切比雪夫距离 ≤ 2（`lastMove < 0` 时跳过）；
3. 数量上限：按先验降序取前 `topM` 名。

支持集小于 2 个点时直接跳过——单点 Dirichlet 恒为 1，只会强化自信，等于没随机。

混合公式不变：`p' = (1-ε)·p + ε·η`，`η ~ Dir(α=0.1)`。这一步抽成了纯函数 `mixRootNoise`，并新增 `lastMove` 透传，目的是能单测。

三道闸是本项目自己加的，源头只借用 AlphaZero 的「根节点加 Dirichlet 噪声」这一条。
