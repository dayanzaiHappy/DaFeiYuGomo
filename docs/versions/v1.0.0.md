# v1.0.0

2026-11-09。首个版本：把桌面版五子棋移植成纯前端网页版。

> 本文件在文档重构时据 `v1.0.0` 快照（提交 `bcfab1f`）与当时的设计记录整理，描述的是 1.0.0 的行为，不代表当前代码。

## 范围

- 15×15 freestyle，五连即胜，无禁手、无交换。
- 人 vs 人（本地双人，悔棋 / 重开 / 返回菜单）。
- 人 vs 机，三档难度；可选执黑 / 执白，执白时 Bot 先下天元。
- 提示：搜索后给出建议落点与理由。
- 四套皮肤、合成音效、移动端适配。
- 不做：存档、回看、账号、联机、国际化。界面仅中文。

## 架构选型

| 决策 | 选择 | 理由 |
|---|---|---|
| 构建 | Vite + TypeScript | 桌面版已是 TS/原生移植思路；Vite 的 `base` 直接对上 GitHub Pages 子路径 |
| 渲染 | Canvas 2D | 225 个交叉点、每帧只重绘棋盘，DOM 方案在移动端会掉帧 |
| 计算 | Web Worker | MCTS 一轮几十到上百毫秒，放主线程会卡住落子反馈与动画 |
| 推理 | `onnxruntime-web` | 桌面版的 v2 模型是 ONNX，浏览器端唯一能直接复用的路径 |
| 框架 | 无 | 页面只有棋盘 + 侧栏 + 几个弹窗，引入框架的收益小于构建体积 |

## 模型与推理

| 项 | 值 |
|---|---|
| 版本 | v2，b6c96，fp32（`v2-b6c96-fp32`） |
| 输入 | `planes[1, 2, 15, 15]`：平面 0 己方、平面 1 对方 |
| 输出 | `policy[225]`、`value[1]` |
| 文件 | `public/models/model-v2.onnx`（约 3.9 MB） |

- 推理在 Worker 内完成，主线程只发请求收结果，协议是自增序号 + `Map` 挂起表。
- 初始化时各测一次 WebGPU 与 WASM，取更快的后端；失败回退 WASM。
- GitHub Pages 没有 COOP/COEP，`SharedArrayBuffer` 不可用，WASM 固定单线程。

## 搜索（初版）

顺序 MCTS，根节点一次性展开半径 4 内的全部合法点，不截断。

- 选择用 UCT：未访问节点取 `0.5 + cPuct · P · √(N+1)`，已访问节点取 `Q + cPuct · P · √N / (1 + n)`，`cPuct = 2.0`。
- 三档只差预算与随机性，参数各自散在 `ai-config.ts` 的 `Record` 里：

| 档位 | sims | τ | ε |
|---|---|---|---|
| 简单 | 4 | 1.0 | 0.25 |
| 普通 | 16 | 0.6 | 0.20 |
| 困难 | 64 | 0.2 | 0.15 |

- 提示：256 次模拟、`topK = 3`、进度每 16 次模拟推一次。
- 噪声：Dirichlet `α = 0.1`，作用于**全部**根子节点。

## 素材与音效

- 不打包任何同人图：形象由 SVG 兜底绘制，首页与气泡使用 `public/images/` 下的头像图，按容器等比缩放显示。
- 背景音乐用一首已获授权的二创作品，其余音效全部 Web Audio 合成。
- iOS 音频约束：`AudioContext` 必须在用户手势内创建或恢复；物理静音键默认会让 Web Audio 静音，提供「静音开关下仍播放」的独立开关；`interrupted` 是 iOS 特有状态，判断要用 `state !== 'running' && state !== 'closed'`，不能只认 `suspended`；页面隐藏时 `suspend`，回前台在下一次手势恢复。

## 部署

- 仓库名与 `base` 绑定：`/DaFeiYuGomo/`。
- push 到 `main` 触发 Actions：`npm ci` → `npm run build` → Pages。
- `prebuild` 把 ORT 的 wasm 运行时复制到 `public/ort/`；产物 `dist/` 可静态托管。
