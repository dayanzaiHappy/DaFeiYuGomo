# v2.2.1

2026-11-18。根节点取子补上必败端的保护：所有着法都已输定时，
噪声不再介入，直接走拖延最久的抵抗。

## 问题

根节点的将杀保护原本只有必胜端：最高分够到必胜分时，采样池只留必胜着法，
防止噪声把赢走输。必败端没有对称逻辑——最高分已是将杀败分时，池内全是败着，
分差在噪声以内的照常进池随机抽。

对手双威胁成杀的局面里，「挡住眼前的成五点」与「送对手立刻成五」的败分
只差几分（将杀步数差的分数换算），远小于弱档的噪声幅度。抽样可能绕过
唯一挡点，观感是「AI 看不见冲四」。

## 修复

- 最高分也是将杀败分时，直接取排序第一的着法（最能拖）。这个判定与普通
  分值域（clamp ±10000）之间隔着两万分空隙，不会误伤非必败局面。
- 候选生成不需要动：挡点的排序取攻防最大值，保证一直在根候选里。

## 为什么对所有难度一刀切

- 必败抵抗的质量由各档自己的搜索深度决定：菜鸟档的「最优」是它认知内的
  最优，看不了多远，难度分层天然保留，不需要额外的旋钮。
- 「挡住眼前成五」是浅搜索就能判定的下限行为，不属于难度差异；漏堵在
  任何档位观感上都是引擎坏了，而不是引擎弱。
- 噪声制造「弱」的定位在非必败局面的漫长过程中，不在终局前一两手。

## 影响面

只影响「最高分是必败将杀分」的取子路径。评分、评级、提示、候选生成与
叶子评估均不变；必胜端保护维持原样。
